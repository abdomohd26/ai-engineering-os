# Task Lifecycle

## Purpose

Transform every meaningful work task into both:

1. A successful delivery.
2. A long-term learning opportunity.

The primary objective is always successful delivery.
Learning should support delivery, not delay it.

---

# Stage 1 — Task Understanding

For every new task:

- Restate the task in your own words.
- Clarify the business objective.
- Define what success looks like.
- Identify assumptions.
- Identify unknowns.
- Ask questions if needed.

Output:
- Problem statement
- Acceptance criteria
- Risks

---

# Stage 2 — Planning

Break the task into milestones.

For each milestone:

- Expected output
- Dependencies
- Risks
- Estimated complexity

Highlight:

- Critical path
- Nice-to-have work

---

# Stage 3 — Knowledge Gap Analysis

Identify:

Already know:
...

Need to review:
...

Need to learn:
...

Can safely ignore:
...

Estimate learning ROI.

Avoid unnecessary deep dives.

---

# Stage 4 — Architecture

Before coding:

Design:

- Components
- Data flow
- APIs
- Storage
- External services
- Failure cases
- Observability

Explain WHY each important decision is made.

---

# Stage 5 — Implementation

During implementation:

- Prefer iterative progress.
- Keep commits logical.
- Explain non-obvious code.
- Highlight AI-generated code.
- Mention assumptions.

---

# Stage 6 — Review

After implementation:

Review:

- Correctness
- Maintainability
- Performance
- Security
- Simplicity
- Business alignment

Challenge important decisions.

Suggest improvements.

---

# Stage 7 — Knowledge Extraction

Extract only knowledge worth keeping.

Examples:

- New engineering concepts.
- Useful patterns.
- Reusable snippets.
- Architecture lessons.
- Mistakes.
- Mental models.

Do NOT store trivial information.

---

# Stage 8 — Roadmap Update

If the task exposed recurring weaknesses:

Update:

- Learning priorities
- Career priorities
- Review topics

Otherwise:

Do not modify the roadmap.

Avoid roadmap churn.

---

# Completion Checklist

Before considering a task complete:

✓ Business objective achieved

✓ Delivery quality acceptable

✓ Code reviewed

✓ Lessons extracted

✓ Knowledge updated (if needed)

✓ Future improvements identified
